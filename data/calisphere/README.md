# data/calisphere — Calisphere reference data for the research campaign

Captured 2026-07-20/21 from calisphere.org (bot-blocked for curl on SPA pages;
scraped via real-browser session — see data/research-authored/CAMPAIGN-STATE.md).

- `beaumont-1828.json` — all 187 items of the Beaumont Library District Local
  History Collection (collection id 1828): ark + browse-tooltip title (dates in
  parentheses where the collection provides them).
- `banning-1582.json` — all 381 items of the Banning Library District Local
  History Collection (collection id 1582), same shape.
- `calisphere_beaumont.json` — prior session's independent scrape of 1828
  (ark+title, no dates); retained as cross-check.
- `calisphere_hashes.json` — ark → `{collection}/{imageHash}` for all 187
  Beaumont items. Image at `https://calisphere.org/clip/{W}x{H}/{value}`;
  native master derivative caps at ~1024 px for this collection.
- `item-metadata-batch1.json` / `-batch2.json` — per-item page metadata
  (title, creator, date, rights statement verbatim, description, type,
  identifier, subject, place, contributing institution), harvested in-browser.
  Merged view: `item-metadata.json`.
- `match-candidates.json` — phase-0 mechanical match candidates
  (token-overlap scores) for every non-researched catalog record vs both
  collections. Generated by scripts/match_calisphere.py.
- `match-plausible.json` — LLM-judged plausible record↔item pairs awaiting
  visual verification. Nothing here is asserted into the catalog until a
  visual same-photograph verdict confirms it.
- `matches-confirmed.json` — visually confirmed same-photograph matches
  (written by the verification workflow pass).
